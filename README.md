# Dropline road data

Offline road data for the navigation in Dropline: Czechia, cars only, plus speed cameras and average-speed
sections. Built from OpenStreetMap with [Valhalla](https://github.com/valhalla/valhalla).

The files are in [Releases](../../releases). They contain map data only.
